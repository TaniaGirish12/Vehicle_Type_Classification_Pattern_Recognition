About This Project

A Pattern Recognition course project benchmarking four CNN architectures for automated vehicle type classification.

Project Overview

VehicleVision is a deep learning system for automated vehicle type classification from traffic and parking images. Four convolutional neural network architectures — a custom baseline and three transfer learning models — were trained and benchmarked on a 7-class vehicle dataset of 5,600 images.

The project demonstrates that transfer learning dramatically outperforms training from scratch, with EfficientNetB0 achieving 99.28% test accuracy using only 4.38M parameters. Grad-CAM visualisations confirm models attend to semantically meaningful vehicle features.

Methodology

  1. EDA & Preprocessing — Resize to 224×224, normalise, stratified 70/15/15 split, class-weight balancing
  2. Data Augmentation — Flip, rotation, zoom, brightness/contrast, hue/saturation, random crop (training only)
  3. Custom CNN — 4× Conv Blocks (32→64→128→256 filters), GlobalAveragePooling, Dense head, trained from scratch
  4. Transfer Learning — Two-phase: (1) frozen base 5 epochs LR=1e-3, (2) fine-tune last 20–30 layers 25 epochs LR=1e-4
  5. Evaluation — Accuracy, Precision, Recall, F1-Macro, ROC/AUC, confusion matrices, inference timing
  6. Explainability — Grad-CAM visualisations of model attention maps
  7. Error Analysis — Per-class error rates and misclassification patterns

Limitations

  • Global traffic not validated
  • Static images — no video stream
